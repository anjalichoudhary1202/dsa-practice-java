## Solution Documentation

For each problem, I aim to include:

1. A link to the original problem.
2. The approach and reasoning.
3. The Java implementation.
4. Time and space complexity.
5. Sample test cases and relevant edge cases.

## Running a Solution

Compile and run a Java file from the terminal:

```bash
javac Candies.java
java Candies
```

Replace `Candies` with the class name of the solution you want to run.
